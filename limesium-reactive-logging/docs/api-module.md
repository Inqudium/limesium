# Module limesium-reactive-logging

Auto-configured WebFlux web filter (Reactor and coroutines) for Spring
Boot (Netty) applications that logs one structured `endpoint_*` line per
HTTP exchange. The field-and-configuration-identical servlet twin is
`limesium-servlet-logging`; the stack-specific guide lives in
[docs/GUIDE.md](https://github.com/Inqudium/limesium/blob/main/limesium-reactive-logging/docs/GUIDE.md),
everything shared by both twins — the table of deliberate stack
differences included — in the
[common guide](https://github.com/Inqudium/limesium/blob/main/docs/GUIDE.md).
